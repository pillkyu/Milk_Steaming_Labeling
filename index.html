홈 스티밍 라벨링

초대받은 사용자만 녹음을 열고 저장할 수 있습니다.

처음 연결하시나요?
  1. 관리자에게 데이터 저장소 초대를 받고 수락합니다.
  2. 소유자(pillkyu)는 세분화된 토큰에서 아래 저장소의 Contents: Read and write를 선택합니다. 초대받은 협업자는 classic 토큰의 repo 권한이 필요합니다.
  3. 협업자용 classic 토큰은 다른 비공개 저장소에도 권한이 있을 수 있습니다. 짧은 만료일로 발급하고 타인에게 공유하지 마세요.
  4. 발급된 토큰을 여기에 입력합니다. 토큰은 현재 탭 메모리에만 보관하며 새로고침하면 다시 입력합니다.

공용 컴퓨터에서는 사용 후 브라우저의 사이트 데이터를 지워 주세요. 저장 전 작업은 이 브라우저에 임시 보관됩니다.
